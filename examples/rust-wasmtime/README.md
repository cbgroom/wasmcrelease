# wasmc Rust and Wasmtime demo

This is copyable reference code, not an SDK. It loads the release's standard Core Wasm compiler, compiles and runs a scalar program, calls a stateful WIT resource Component, and binds one explicit Host import for another Lib Component.

From this directory in the assembled public release:

```bash
cargo test --locked
cargo run --locked
```

Expected values are generated bytes `44`, scalar `17`, resource `15`, and Host-backed result `42`. The Host grants only `wasmc:host-clock/clock-host@0.0.1#now`.

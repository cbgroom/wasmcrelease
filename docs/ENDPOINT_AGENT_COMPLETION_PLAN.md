# Endpoint Agent completion plan

Status: active architecture workstream; not admitted or released.

The fixed Host remains domain-neutral. Each milestone is implemented by exact
Lib packages and must retain target-scoped behavior evidence before lifecycle
promotion.

1. **Dynamic Lib product path** — freeze the native descriptor schema, lower
   System Lib WIT to Wasm/Component artifacts, dynamically load exact providers,
   then add admission, catalog, discovery, install, update and rollback.
2. **Observe/act/verify/reconcile contract** — unify stable surface/resource IDs,
   generations, semantic and pixel observations, targeted actions, cancellation,
   postconditions and stale-state rejection across platforms.
3. **Concurrent App surfaces** — qualify real WKWebView/DOM observation and
   virtual actions on iOS, retain Android semantic UI plus uinput, and prove that
   Agent activity on one surface does not consume or corrupt user interaction on
   another. This milestone is **in progress**.
4. **Durable task and cloud continuity** — generalize bounded outboxes, retain
   server-side idempotency across server restart, qualify public-CA networking,
   backpressure, offline/online transitions and multi-device reconciliation.
5. **Platform scheduling and wake** — compose iOS push/background transfer,
   Android foreground service/WorkManager/FCM and Linux service supervision with
   one durable task journal while preserving platform delivery limits.
6. **Local Agent runtime** — model artifact lifecycle, CPU/GPU/NPU selection,
   bounded context and memory, thermal/power response, local/cloud routing and
   restart-safe action journals.

Completion requires separate evidence for qualified, admitted, released,
discoverable and installable states. Simulator evidence remains Simulator-scoped.
